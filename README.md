# MemCleaner

Маленькая утилита очистки памяти для Windows. Подрезает рабочие наборы всех
процессов, чистит standby / modified page lists и сбрасывает файловый кэш —
тот же механизм, что у Mem Reduct, плюс трей-режим и автозагрузка.

## Возможности

- Интерактивное меню при запуске — чистка, трей, автозагрузка, настройки
- Глубокая чистка: `EmptyWorkingSet` + purge standby/modified + file cache
- Трей-режим с авто-чисткой **по порогу** — дёргает процессы только когда
  память реально кончается (по умолчанию ≤ 25% свободной)
- Автозагрузка через Task Scheduler — elevated, без UAC при каждом логине
- Всегда запускается от администратора (UAC один раз при старте)
- Защита от двойного запуска — одно окно/один трей максимум
- Лог всех действий: `%LOCALAPPDATA%\MemCleaner\log.txt`
- Исключения из чистки: `ClipBar`, `ffmpeg`, `ffprobe`, `java`/`javaw`,
  `MemCleaner` — запись и игра не фризят

## Установка

Скачай `MemCleaner.exe` из [Releases](../../releases) — self-contained,
.NET не нужен. Запусти, подтверди UAC — откроется меню.

## Меню

```
============ MemCleaner 1.0 ============
Свободно     : 9764 MB из 32638 MB (29%)
Автозагрузка : выкл
Режим        : администратор (полная чистка)
Режим трея   : каждые 60с, чистить при <= 25% свободной
----------------------------------------
  1 — Очистить память сейчас
  2 — Запустить в трее (фон, авто-чистка)
  3 — Включить автозагрузку
  4 — Выключить автозагрузку
  5 — Настройки (порог %, интервал сек)
  0 — Выход
```

## CLI

```
MemCleaner.exe --tray          иконка в трее + авто-чистка
MemCleaner.exe --watch         цикл чисток в консоли
  --interval N  / -i N         пауза между проверками, сек (60)
  --threshold N / -t N         чистить при свободной <= N% (25; 0 = всегда)
MemCleaner.exe --install       добавить в автозагрузку
MemCleaner.exe --uninstall     убрать из автозагрузки
MemCleaner.exe --status        показать задачу автозапуска
```

В трее: правый клик — **Clean now / Pause / Exit**, в подсказке — сколько
освободилось последний раз.

## Сборка

```
dotnet publish -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true \
  -p:PublishTrimmed=true -o dist
```
